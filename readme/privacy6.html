🔒 سياسة الخصوصية

في موقع TMG WEB ZONE، نعتبر خصوصية زوارنا ومستخدمي أدواتنا ذات أهمية بالغة بالنسبة لنا.

1. الملفات والبيانات الشخصية

أدواتنا تحترم خصوصيتك بالكامل. أي ملفات تقوم برفعها لاستخدام الأدوات المساعدة تُعالج بأمان ولا يتم مشاركتها إطلاقاً مع أي أطراف خارجية.

2. ملفات تعريف الارتباط (Cookies)

قد يستخدم الموقع ملفات الكوكيز لتحسين تجربة تصفحك وتحليل الزيارات عبر خدمات مثل Google Analytics لتقديم خدمة أفضل.

3. الإعلانات

قد يتم عرض إعلانات عبر شبكات إعلانية مثل Google AdSense، والتي قد تستخدم كوكيز لعرض إعلانات ملائمة بناءً على زياراتك السابقة لموقعنا أو مواقع أخرى.
